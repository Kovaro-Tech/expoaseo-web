# Plus Jakarta Sans

Variable WOFF2, normal, weights 400–800, Latin subset including Spanish.
Same family and weights used by the original Google Fonts stylesheet.

Source: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2

License: SIL Open Font License 1.1; see OFL.txt (from
https://github.com/google/fonts/tree/main/ofl/plusjakartasans).

Vite fingerprints the font. HTML preloads that same fingerprinted URL and CSS
uses it with font-display: swap. No font generation or network access is needed
during production builds.
